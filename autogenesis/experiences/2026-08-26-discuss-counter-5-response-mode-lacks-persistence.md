## Context

Sequential discussion of Original Counter 5 (existing Discussion mode already solves the lightweight need).

## What happened

User response:

- Yes: the graph is a new capability that Discussion mode lacks.
- Discussion in Autogenesis is a discipline, but it lacks persistence, tracking, and pruning.
- The discussion ends up in a conclusion or action.
- The graph lets us backtrack where that conclusion or action comes from.

This accepts that the mode remains the lightweight process boundary (zero implement authority, no short-circuit) and pins the graph as the missing substrate: persist the conversation, track branches, prune via TVA, and provide lineage from later conclusions/actions back to the originating discussion nodes.

## Outcome

Counter 5 is substantially addressed. The mode and the graph are complementary, not redundant: mode = discipline and authority boundary; graph = persistence, tracking, pruning, and backtrackable lineage.

Low residual (design-time): how a conclusion or action is linked back to the discussion graph so lineage is queryable without collapsing Discussion mode into a Run.
