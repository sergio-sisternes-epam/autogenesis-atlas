# Module activation boundary

The user selected "Parent-routed modules with skill-shaped packaging
(Recommended)" on 2026-09-11.

Modules have their own SKILL.md and optional local references, but the parent
skill remains their activation route. Independent catalogue registration and
standalone activation are not intended consequences of this packaging change.
Parent workflow prerequisites remain applicable.

This pin settles activation intent, not implementation details or migration
approval. The scope of conversion for existing internal helpers remains open.
