## Causes (conversation evidence)

1. **Plan template teaches the word.** Autogenesis plan template includes `## Residual risks`. Agents treat “residual” as the name of leftover *work*, not leftover *risk*.
2. **Discuss sprout text names the folder.** `discuss/references/paths/sprout.md` says write the protostar “often `residuals/` or beside the origin”. That is a direct instruction to create the folder this user objects to.
3. **Older Autogenesis experiences model the habit.** Pages titled “residuals captured for the future” (`2026-08-26-discuss-low-residuals-captured` and Counter 3/5 residual-captured) store future work as experiences tagged `residuals`, not as `type: protostar`.
4. **Exit pressure.** Design/implement Exit wants deferred items on disk. Without a hard “protostar only” rule, the agent invents `autogenesis/residuals/` as a tidy bucket. This session did that on gamma and then copied it to medium.
5. **Homonym.** Residual risk ≠ residual work ≠ leftover file. One English word, three jobs.

## What is not the cause (this session)

Insufficient evidence that SCHEMA requires a `residuals/` folder. Gamma and medium SCHEMAs list plans/experiences/decisions/work only. The folder was invented at implement/close time.
