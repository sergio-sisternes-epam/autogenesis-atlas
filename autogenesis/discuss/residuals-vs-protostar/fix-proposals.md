## Proposals

**P1. Ban the folder.** Autogenesis space allows `plans/ experiences/ decisions/ work/ discuss/` only. `autogenesis/residuals/` is a defect. Existing folders become migrate-to-protostar work, not a living bucket.

**P2. Exit rule.** When a Run parks future work, write `type: protostar` via discuss sprout, beside the origin work or plan. Search key remains `kva: alive`. No third backlog.

**P3. Rename plan section.** `## Residual risks` → `## Accepted risks` or `## Open risks` so the word residual stops meaning “more work”.

**P4. Fix discuss sprout copy.** Delete “often `residuals/`”. Say “beside the origin node” only.

**P5. Do not rename historical experience titles** that already say residual-captured. Leave them; new pages are protostars.
