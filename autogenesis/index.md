# Autogenesis space

All content **created by Autogenesis** in this Atlas is scoped here so that, on other skills, subject-native memory can live at the Atlas root while Autogenesis work stays namespaced.

| Folder | Role |
|--------|------|
| [experiences/](experiences/) | Runs, migrations, implement records |
| [decisions/](decisions/) | Pinned discipline and design decisions |
| [work/](work/) | `work_id` hubs |
| [plans/](plans/) | Formal design plans (`type: plan`) |
| [discussions/](discussions/) | Conversation origins and unresolved branches |

Promote templates live at the Atlas root [`../templates/`](../templates/) (not inside this space, so they are not concept pages).

**Plan path convention:** `autogenesis/plans/<work_id>.md`
