## Decision

After **material** knowledge change, **subject is always in scope**. Empty peer graph ≠ empty output.

Each skill in scope must emit:

1. classification + rationale + uncertainty + evidence  
2. **Update proposals** for SKILL.md, paths/modules, knowledge contracts, open tasks — or explicit **none — rationale**  
3. Decision gate: **proposal only** this run; implement needs approval/PR  

Soft “consider later” alone is **incomplete**.  
“Do not auto-create” means do not **implement** in-run; sharp proposals are still required when warranted.

See path module `references/paths/reevaluate.md`.

Migrated from okf-wiki knowledge page `reevaluate-proposal-template` during work `autogenesis-okf-wiki-to-atlas-migration-v1`. Substrate authority is now Atlas.
